Brings the per calendar event count, ICS export and ICS import already offered on user calendars (#1067, #1069, #1075) to the calendars a domain owns.

## APIs

```
GET  /domains/{domain}/team-calendars/{teamCalendarId}/eventCount
GET  /domains/{domain}/resources/{resourceId}/eventCount
=> {"count": 805}

POST /domains/{domain}/team-calendars/{teamCalendarId}?action=export
POST /domains/{domain}/resources/{resourceId}?action=export
=> ICS data body response

POST /domains/{domain}/team-calendars/{teamCalendarId}?action=import
POST /domains/{domain}/resources/{resourceId}?action=import
<= ICS data body request
=> {"taskId": "..."} - plans a task importing the events into the calendar
```

## Implementation

Team calendars and resources are both plain DAV calendars that no user owns: they live at `/calendars/{id}/{id}` and are reached with the technical token of their domain. `CalDavClient` export / import / event listing thus gained technical token variants, and a single set of handlers (`DomainCalendarContentRoutes`) serves the two URL families - only the way the identifier is resolved differs.

Imports plan a `domain-calendar-import` task, attributed to its domain so that it shows up in the domain scoped task routes:

```json
{
  "type": "domain-calendar-import",
  "additionalInformation": {
    "domain": "linagora.com",
    "calendarType": "team-calendar",
    "calendarId": "64f1c2b8e4b0a1d2c3f4e5a6",
    "totalEventCount": 12,
    "importedEventCount": 12,
    "failedEventCount": 0
  }
}
```

As on user calendars, VEVENTs are grouped by UID - a master event and its recurrence overrides yield a single event - and are stored alongside the time zones they rely on, so the output of the export routes can be imported back as is.

Resources flagged as deleted keep their calendar: their content stays readable through the counting and export routes, but may no longer be written to.

## Tests

`DomainCalendarContentRoutesTest` (35 tests against Sabre DAV) covers both families through the same parameterized scenarios: counting, export, import, ICS round trip, overwriting events sharing a UID, invalid action / body, cross domain isolation, plus the deleted resource cases. `UserCalendarRoutesTest`, `TeamCalendarRoutesTest`, `ResourceRoutesTest`, `DomainTasksRoutesTest` and `CalDavClientTest` were run as well and pass.
